## 🚀 Quick Start

### Option 1: Clone & Open (Recommended)

```bash
# Clone the repository
git clone https://github.com/Preetham_111/zenhabit.git

# Navigate into the folder
cd zenhabit

# Open in your browser
open index.html
```

> No `npm install` needed — it's plain HTML + JavaScript! Just open `index.html` in any browser.

---

### Option 2: Use Live Server (for development)

If you have VS Code:

1. Install the **Live Server** extension
2. Right-click `index.html`
3. Click **"Open with Live Server"**

Or with Node.js:

```bash
# Install a simple server globally
npm install -g live-server

# Run it
live-server
```

---

### Option 3: Download ZIP

1. Go to the [GitHub repo](https://github.com/Preetham_111/zenhabit)
2. Click **Code → Download ZIP**
3. Extract and open `index.html`
